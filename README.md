# VITAL ASSESS（バイタルアセス）

バイタルサインと心電図から、緊急度・考えられる疾患・次の行動を整理する、医療従事者向けのアセスメントアプリです。
診療の参考と学習のためのツールで、医療機器ではありません。

## 機能

**バイタルサイン評価**（`#vital`）
- モニター画面・電子カルテ・紙の記録を撮影すると、HR・血圧・SpO2・RR・体温を読み取り、確認してから入力欄に反映（Claude 上で開いたとき）
- 主訴・既往歴は自由入力（キーワードを認識。「胸痛なし」のような否定は数えない）。性別・年齢・左右の血圧・JCS・GCSなど、すべて任意で1項目から評価
- 年齢帯（新生児〜高齢者）に応じた正常値で、正常・注意・異常を色・アイコン・文字で表示
- ショックインデックス、血圧左右差、平均血圧、脈圧、qSOFA、NEWS2 を自動で計算
- ふだんは緊急度と算出指標だけを表示し、「疾患推定・アドバイスを見る」ボタンで、疾患・病態の候補（支持する所見・合わない所見・確認したい追加情報）、見逃し禁止疾患、次の行動と再測定の目安を表示
- すべての結果に出典と版を表示
- 時刻つきの記録と、再測定の経過グラフ
- ありえない値（例：体温 365℃）は確認を出し、確認が済むまで評価に使わない

**心電図評価**（`#ecg`）
- 撮影・写真の読み込みと電子キャリパー（縮尺合わせ、PR・QRS・QT・RRの計測）
- 写真から所見をAIで読み取り（Claude 上で開いたとき）、ルール判定と並べて一致・不一致を表示
- 所見からのリズム判定（最大3候補）、ST変化からの梗塞部位の推定、QTc（Bazett・Fridericia）
- 心停止系の波形を疑うときは、まず患者を確認するよう警告
- 波形クイズ：33種類の合成波形（洞調律・上室性・心室性・心停止・房室ブロック・脚ブロック・WPW・ST変化・高K・QT延長・ブルガダ・ペースメーカー）をランダムに出題。解答後に、考えられる疾患・原因とリスクを表示

## 構成

| ファイル | 役割 |
| --- | --- |
| `js/va-vital-engine.js` | バイタル評価のルール判定（画面から独立） |
| `js/va-ecg-engine.js` | 心電図のルール判定と、見本・クイズ用の合成波形 |
| `index.html` | すべての画面（#home・#vital・#ecg・#terms を切り替える1ページ構成） |
| `js/va-vital.js` / `js/va-ecg.js` / `js/va-home.js` / `js/va-app.js` | 各画面と画面の切り替え |
| `js/va-reader.js` | 写真の読み取り（Claude 上で開いたときの `claude.use("sample")`） |
| `js/va-common.js` | 記録の保存（端末内）と出典の一覧 |

判定ロジックの確認：

```sh
npm test
```

## 動かす

Webアプリとしては、このフォルダをそのまま静的サイトとして公開すれば動きます（オフライン対応）。

スマホアプリ（Capacitor）にする場合：

```sh
npm install
npx cap add ios      # 初回のみ（Macが必要）
npx cap add android  # 初回のみ
npm run sync
npm run open:ios     # または npm run open:android
```

アプリID は `jp.vitalassess.app`（`capacitor.config.json`）です。
